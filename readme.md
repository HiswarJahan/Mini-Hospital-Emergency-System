# Mini Hospital Emergency Management System

## Introduction

This project is a Java-based Mini Hospital Emergency
Management System developed for the CIT300 Data Structures
and Algorithms assignment.

## Data Structures Used

### 1. Binary Search Tree
Used to store and search patient records using Patient ID.

### 2. Queue
Used to manage emergency patients using FIFO
(First-In, First-Out).

### 3. Stack
Used to store completed treatment records using LIFO
(Last-In, First-Out).

### 4. Singly Linked List
Used to store the previous hospital visits of patients.

## Main Features

- Register a patient
- Search for a patient
- Delete a patient
- Display patients
- Add emergency patient
- Treat next patient
- Display waiting queue
- Add treatment record
- Display treatment history
- Add patient visit
- Search visit
- Remove visit
- Display visit history

## Technologies Used

- Java
- Eclipse IDE
- GitHub

## How to Run

1. Open the project in Eclipse.
2. Run HospitalManagementSystem.java.
3. Select an option from the menu.
4. Follow the instructions displayed on the screen.

## Conclusion

This project demonstrates how different data structures
can be used to manage hospital emergency operations.
